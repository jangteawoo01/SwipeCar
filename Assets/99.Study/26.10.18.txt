translate는 게임 오브젝트를 현재 좌표에서 인수 값만큼 이동시키는 메서드
인수가 현재 좌표 값을 직접 나타내는 것은 아닙니다
현재 좌표의 상대적인 이동 값을 나타냅니다.
예를 들어 Translate(0,3,0)dms 0,3,0의 좌표로 이동하는 것이 아니라 현재
지점에서 Y축 방향으로 3만큼 이동한다는 의미


translate 메서드를 사용하면 이동 방향은 월드 좌표계가 아니라 로컬 좌표계로 계산됩니다.
따라서 오브젝트가 회전하면 방향이 회전한 좌표계로 계산됩니다.
오브젝트가 회전하면서 동시에 이동할 때는 조심해야 합니다.
ㄴ회전된 상태의 오브젝트가 있는데, 이것을 로컬 좌표계로 이동되지 않고, 월드 좌표계로 움직이게 하고 싶을 때 어떻게 해야 할까?

해당 회전 되어 있는 오브젝트를 우클릭시 Create Empty Parent를 생성후 해당 오브젝트 상위 Parent에 스크립트를 넣고 실행하면 됩니다

로컬 좌표가 아니라, 로컬 좌표를 갖고 있는 오브젝트의 상위 오브젝트(얘는 월드 좌표계랑 같은 좌표를 갖고 있다)를 움직이게 하면 간단하다.

UI 
1. UI 부품을 Scene뷰에 배치한다
2. UI를 갱신하는 감독 스크립트를 작성한다.
3. 빈 오브젝트를 만들고 작성한 스크립트를 적용한다.

UI 생성 방법 (Text)
UI(Canvas) -> Legacy -> Text

EventSystem
UI Text를 추가하면 Hierarchy창에 Canvas와 EventSystem이 추가됩니다.
이 EventSystem은 사용자 입력과 UI 요소를 중간에서 이어 주는 오브젝트를 UI를 사용할 때 반드시 필요합니다.
EventSystem을 사용하면 입력 할당이나 무효화 등 키와 마우스 설정을 변경할 수 있습니다.

Rect Transform
UI에서는 좌표를 표시하는데 Transform이 아닌 Rect TransForm을 사용합니다.

Transform에서는 위치, 회전, 크기를 변경할 수 있고,
Rect Transform에서는 위치, 회전 크기는 물론 피벗과 앵커를 변경할 수 있습니다.

피벗은 회전 또는 확대나 축소를 할 때 쓰는 중심 좌표입니다.

앵커는 UI리소스를 배치할 때 기준이 되는 위치를 지정합니다.

UI script를 작성시 
using UnityEngine.UI;를 작성을 해야 합니다.

Car UI 진행 
Text가 있고, Text에 다가는 Car와 Flag 사이의 거리를 표시 해줘야 합니다.

거리를 알아야 하고, 표시해야 할 Text 타입의 오브젝트에 Text란에다가 거리를 표시 해줘야 합니다.

거리를 알아야 한다는 말은 Car와 Flag 오브젝트의 위치값을 알아야 한다는 말입니다.

Car와 Flag 오브젝트의 x좌표를 알아내서 그 차이를 우리가 만든 Distance_text 오브젝트의 Text 란에다가 표시를 해주면 될 것입니다.

ToString은 값을 문자열로 변환하는 메서드
인수에는 값을 표시할 형식을 지정할 수 있습니다.
인수에 넣을 수 있는 형식 대표적인 것

정수형 D [자릿수] 
정수를 표시할 때 사용한다. 지정한 자릿수를 채우지 않으면 왼쪽에 0이 삽입된다.
(456).ToString("D5") -> 00456

고정 소수점형 F [자릿수] 
소수를 표시할 대 소수점 이하 자릿수를 조정한다.
(12.3456).ToString("F3") -> 12.345

유니티에서는 AudioSource 컴포넌트로 효과음을 냅니다
AudioSource 컴포넌트를 써서 스와이프할 때 '붕~' 하는 효과음을 넣어 봅시다
효과음을 낼 때는 다음 세 단계를 거칩니다.

1. 효과음을 낼 오브젝트에 AudioSource 컴포넌트를 적용한다.
2. AudioSource 컴포넌트에 효과음을 설정한다.
3. 효과음을 울리고 싶은 시간에 스와이프하면 Plat 메서드를 호출한다.
